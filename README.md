# 🚀 Mars to Table: Bioregenerative Food System Simulation (MHFM)

Python simulation modules for Mars to Table and BioSim integration.

## Run

```bash
python -m marstotable_biosim --scenario nominal --output results/
```

An end-to-end, vertically integrated life support and space-nutrition framework engineered for a 15-member surface expedition crew on Mars over a 500-Sol mission footprint. 

The project features a high-fidelity Python-based biosimulation model (`marstotable_biosim`) built to interface with the **BioSim** testing platform, achieving a **96.5% closed-loop water recovery efficiency**.
